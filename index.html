What is Code?

        

            
Code is a set of instructions that tells a computer what to do. However, different types of code do completely different jobs!

            
    
                
  • HTML (Markup Language): HTML stands for HyperText Markup Language. It is not a programming language; it is a structural language. Think of HTML like the bricks, wood, and blueprint of a house. It tells the browser where to put text, images, and links.
    • 
                
  • Python / JavaScript / C++ (Programming Languages): These are true programming languages. They handle logic, math, memory, and decision-making. If HTML is the blueprint of the house, programming languages are the electricity and plumbing that make the house actually do things.
    • 
                
  • CSS (Style Sheet): Used alongside HTML, CSS is like the paint, wallpaper, and interior design of the house. It makes the HTML look pretty!
    • 
            

        


        
HTML Glossary

        

            

                Tag
                The basic building block of HTML. They are wrapped in angle brackets. Almost all tags come in pairs (opening and closing).

Example: <p> and </p>
            

            

                Element
                An entire block of HTML, including the opening tag, the content inside, and the closing tag.

Example: <p>Hello</p>
            

            

                Attribute
                Extra information added inside an opening tag to change how it behaves or looks.

Example: src or href
            

            

                href
                Stands for "Hypertext Reference". It is the attribute used in links (<a>) to tell the browser what website URL to go to.
            

            

                src
                Stands for "Source". It is the attribute used in images (<img>) to tell the browser where the picture file is located.
            

            

                Syntax
                The "grammar" or spelling rules of code. If your syntax is wrong (like forgetting a closing bracket >), the computer won't understand you!
